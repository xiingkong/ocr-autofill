终端命令： python ocr_server.py cdk add-daily <code1> [code2 ...]
一次性 CDK（跑完一轮自动删）： python ocr_server.py cdk add-once <code>
查看/删除/重置： python ocr_server.py cdk list · cdk remove <code> · cdk reset <code>
